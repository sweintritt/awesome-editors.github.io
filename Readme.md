Awesome Editors
================

<div align="center">

![Icon](./icon_256.png)

</div>

A curated list of awesome editors ranging from simple like nano to full blown IDE like IntelliJ.

Visit the  [website](https://sweintritt.github.io/awesome-editors/) to search and
filter editors more easily and to get more information about each editor. Like license or
the language it is written in.

![Screenshot](./screenshot.png)

---
- [vim](https://www.vim.org/) - One of the two classic highly configurable and extensible terminal based text editors![License: GPL-compatible](https://img.shields.io/badge/license-GPL--compatible-006060)
- [neovim](https://www.neovim.io/) - Vim-fork focused on extensibility and usability![License: Apachev2](https://img.shields.io/badge/license-Apachev2-006060)
- [Emacs](https://www.gnu.org/software/emacs/) - The other one of the two classic highly configurable and extensible terminal based text editors![License: GPLv3](https://img.shields.io/badge/license-GPLv3-006060)
- [micro](https://micro-editor.github.io/) - A modern and intuitive terminal-based text editor![License: MIT](https://img.shields.io/badge/license-MIT-006060)
- [Kakoune ](https://kakoune.org/) - A code editor with a strong focus on interactivity and multiple selections![License: Unilicense](https://img.shields.io/badge/license-Unilicense-006060)
- [Helix ](https://helix-editor.com/) - A post-modern modal text editor inspired by Kakoune and Neovim![License: MPLv2](https://img.shields.io/badge/license-MPLv2-006060)
- [editor](https://github.com/jmigpin/editor) - A simple and fast GUI text editor inspired by the acme editor from Plan 9![License: MIT](https://img.shields.io/badge/license-MIT-006060)
- [kilo (in Go)](https://github.com/bediger4000/kilo-in-go) - A small and simple terminal-based text editor written in a single file with just 1000 lines of Go![License: none](https://img.shields.io/badge/license-none-006060)
- [jedit](https://www.jedit.org/) - A programmer's text editor written in Java. It can be configured as a rather powerful IDE through the use of its plugin architecture.![License: GPLv2](https://img.shields.io/badge/license-GPLv2-006060)
- [Lite XL](https://lite-xl.com/) - A lightweight text editor written in Lua.![License: MIT](https://img.shields.io/badge/license-MIT-006060)
- [Geany](https://www.geany.org/) - A small and lightweight IDE![License: GPLv2](https://img.shields.io/badge/license-GPLv2-006060)
- [Fleet](https://www.jetbrains.com/fleet/) - Editor made by JetBrains, with support for multiple languages and AI assistant![License: commercial (public preview)](https://img.shields.io/badge/license-commercial%20%28public%20preview%29-006060)
- [Gnome Builder](https://apps.gnome.org/de/Builder/) - An IDE for writing GNOME-based software.![License: GPLv3](https://img.shields.io/badge/license-GPLv3-006060)
- [IntelliJ Community Edition](https://www.jetbrains.com/idea/) - Professional Java IDE![License: Apachev2](https://img.shields.io/badge/license-Apachev2-006060)
- [Kate](https://kate-editor.org) - Advanced text editor of the KDE project.![License: LGPLv2, MIT](https://img.shields.io/badge/license-LGPLv2%2C%20MIT-006060)
- [VSCodium](https://vscodium.com/) - VSCodium is a community-driven, freely-licensed binary distribution of Microsoft’s editor VS Code.![License: MIT](https://img.shields.io/badge/license-MIT-006060)
- [Zed](https://zed.dev/) - Zed is a minimal code editor crafted for speed and collaboration with humans and AI.![License: AGPL, GPL, Apache](https://img.shields.io/badge/license-AGPL%2C%20GPL%2C%20Apache-006060)
- [Lapce](https://lap.dev/lapce/) - Lightning-fast and Powerful Code Editor ![License: Apachev2](https://img.shields.io/badge/license-Apachev2-006060)
- [Pulsar](https://pulsar-edit.dev/) - Pulsar is a fork of the discontinued Atom editor - assuming its mission of being a zero-compromise combination of hackability and usability.![License: MIT](https://img.shields.io/badge/license-MIT-006060)
- [chr](https://github.com/chr-editor/chr) - The chr terminal editor is inspired by the turbo pascal editor.![License: BSLv1](https://img.shields.io/badge/license-BSLv1-006060)
- [Theia](https://theia-ide.org/) - Eclipse Theia is an extensible framework to develop full-fledged multi-language Cloud & Desktop IDEs and tools with state-of-the-art web technologies.![License: EPLv2, GPLv2, MIT](https://img.shields.io/badge/license-EPLv2%2C%20GPLv2%2C%20MIT-006060)
- [Atom](https://atom-editor.cc/) - Atom is a hackable text editor for the 21st century.![License: MIT](https://img.shields.io/badge/license-MIT-006060)
- [Microsoft edit](https://github.com/microsoft/edit) - This editor pays homage to the classic MS-DOS Editor, but with a modern interface and input controls similar to VS Code.![License: MIT](https://img.shields.io/badge/license-MIT-006060)
- [nano](https://www.nano-editor.org/) - Small and friendly text editor. It copies the look and feel of Pico.![License: GPLv3](https://img.shields.io/badge/license-GPLv3-006060)
