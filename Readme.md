Awesome Editors
================

<div style="text-align: center;">

![Icon](./icon_256.png)

</div>

A curated list of awesome editors ranging from simple like nano to full blown IDE like IntelliJ.

Visit the  [website](https://sweintritt.github.io/awesome-editors.github.io/) to search and
filter editors more easily and to get more information about each editor. Like license or
the language it is written in.

![Screenshot](./screenshot.png)

---
- [vim](https://www.vim.org/) - One of the two classic highly configurable and extensible terminal based text editors<kbd>GPL-compatible</kbd>
- [neovim](https://www.neovim.io/) - Vim-fork focused on extensibility and usability<kbd>Apachev2</kbd>
- [Emacs](https://www.gnu.org/software/emacs/) - The other one of the two classic highly configurable and extensible terminal based text editors<kbd>GPLv3</kbd>
- [micro](https://micro-editor.github.io/) - A modern and intuitive terminal-based text editor<kbd>MIT</kbd>
- [Kakoune ](https://kakoune.org/) - A code editor with a strong focus on interactivity and multiple selections<kbd>Unilicense</kbd>
- [Helix ](https://helix-editor.com/) - A post-modern modal text editor inspired by Kakoune and Neovim<kbd>MPLv2</kbd>
- [editor](https://github.com/jmigpin/editor) - A simple and fast GUI text editor inspired by the acme editor from Plan 9<kbd>MIT</kbd>
- [kilo (in Go)](https://github.com/bediger4000/kilo-in-go) - A small and simple terminal-based text editor written in a single file with just 1000 lines of Go<kbd>none</kbd>
- [jedit](https://www.jedit.org/) - A programmer's text editor written in Java. It can be configured as a rather powerful IDE through the use of its plugin architecture.<kbd>GPLv2</kbd>
- [Lite XL](https://lite-xl.com/) - A lightweight text editor written in Lua.<kbd>MIT</kbd>
- [Geany](https://www.geany.org/) - A small and lightweight IDE<kbd>GPLv2</kbd>
- [Fleet](https://www.jetbrains.com/fleet/) - Editor made by JetBrains, with support for multiple languages and AI assistant<kbd>commercial (public preview)</kbd>
- [Gnome Builder](https://apps.gnome.org/de/Builder/) - An IDE for writing GNOME-based software.<kbd>GPLv3</kbd>
- [IntelliJ Community Edition](https://www.jetbrains.com/idea/) - Professional Java IDE<kbd>Apachev2</kbd>
- [Kate](https://kate-editor.org) - Advanced text editor of the KDE project.<kbd>LGPLv2, MIT</kbd>
- [VSCodium](https://vscodium.com/) - VSCodium is a community-driven, freely-licensed binary distribution of Microsoft’s editor VS Code.<kbd>MIT</kbd>
- [Zed](https://zed.dev/) - Zed is a minimal code editor crafted for speed and collaboration with humans and AI.<kbd>AGPL, GPL, Apache</kbd>
- [Lapce](https://lap.dev/lapce/) - Lightning-fast and Powerful Code Editor <kbd>Apachev2</kbd>
- [Pulsar](https://pulsar-edit.dev/) - Pulsar is a fork of the discontinued Atom editor - assuming its mission of being a zero-compromise combination of hackability and usability.<kbd>MIT</kbd>
- [chr](https://github.com/chr-editor/chr) - The chr terminal editor is inspired by the turbo pascal editor.<kbd>BSLv1</kbd>
- [Theia](https://theia-ide.org/) - Eclipse Theia is an extensible framework to develop full-fledged multi-language Cloud & Desktop IDEs and tools with state-of-the-art web technologies.<kbd>EPLv2, GPLv2, MIT</kbd>
- [Atom](https://atom-editor.cc/) - Atom is a hackable text editor for the 21st century.<kbd>MIT</kbd>
- [Microsoft edit](https://github.com/microsoft/edit) - This editor pays homage to the classic MS-DOS Editor, but with a modern interface and input controls similar to VS Code.<kbd>MIT</kbd>
- [nano](https://www.nano-editor.org/) - Small and friendly text editor. It copies the look and feel of Pico.<kbd>GPLv3</kbd>
